# Library provenance

The local Adapter_Interfaces symbols copy the submitted KiCad Connector Conn_01x03_Pin, Connector Conn_01x02_Socket and Mechanical MountingHole graphics and pins. Names, footprint filters and descriptions were adapted for portable project use; no pin numbering or electrical type changed. Adapter_F469 remains the submitted library.

The new FanPinHeader_1x03_P2.54mm_Vertical and JST_NV_B02P-NV_1x02_P5.00mm_Vertical footprint geometry comes from the installed KiCad 9.0.2 libraries, by the KiCad library community. Library paths and 3D associations are local. The 3.5 mm mounting-hole copy adds an 8 mm hardware courtyard. Original drill and copper pad geometry are unchanged.
